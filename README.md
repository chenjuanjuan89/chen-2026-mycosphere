Description:

This repository contains the complete set of log files and raw gene tree outputs generated from a comprehensive phylogenomic analysis pipeline. It serves as a supplementary data archive for reproducibility and further interrogation of phylogenetic signals across genomic datasets.

The included analyses leverage four widely used tools in phylogenomics:

PhyloNet – for inferring and evaluating phylogenetic networks, accounting for incomplete lineage sorting (ILS) and hybridization.

PhyParts – for quantifying bipartition support across gene trees and assessing phylogenetic concordance.

PhyTop – for exploring phylogenetic topology distributions and identifying dominant phylogenetic signals.

QuartetScores – for computing quartet-based measures (e.g., quartet fit, concordance factors) to evaluate discordance patterns.
